Project Overview

This project is part of the Discovery Web Piscine. In this project, I learned some basic concepts of Linux, Git, GitHub, and version control.

I practiced using the Linux terminal to create and manage files and directories. I also learned how to use Git to save my changes and upload my project to GitHub.

Technologies Used

- Linux
- Git
- GitHub
- Markdown
- SSH

Git Workflow

The basic Git workflow I used in this project is:

1. Create or edit a file.
2. Use "git status" to check the changes.
3. Use "git add" to prepare the changes.
4. Use "git commit" to save the changes in Git.
5. Use "git push" to upload the changes to GitHub.

Using this process helps me keep track of my work and avoid losing previous changes.

Why Git Makes Development Easier

Git makes development easier because it keeps a history of the changes made to a project.

Git helps protect my code because I can see previous versions of my files. If I make a mistake, I can check the previous changes and understand what happened.

Git also keeps track of the development history. Each commit represents a change that I made to the project, so it is easier to follow how the project was developed.

Git is also useful when working with other developers. Each person can work on the project and share their changes using Git. This makes teamwork easier and helps organize the different changes.

Security

In this project, I also learned about SSH authentication using an Ed25519 key.

The private key should always be kept secret and should not be uploaded to GitHub.

Only the public key can be shared with GitHub for authentication.

Conclusion

This project helped me understand the basics of Linux, Git, and GitHub. I practiced creating and managing files, tracking changes with Git, and uploading my work to a GitHub repository.

I also learned the basic idea of using SSH keys for more secure authentication.
